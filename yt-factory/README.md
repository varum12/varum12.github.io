# YT Factory: конвейер для Shorts и длинных видео

Вы пишете сценарий (или просите Claude его написать), запускаете одну команду и получаете:

- готовое видео (9:16 для Shorts или 16:9 для длинных);
- озвучку AI-голосом;
- субтитры по одному слову по центру экрана, числа и ключевые слова выделены жёлтым;
- быструю смену кадров каждые ~1.6 сек с «ударом» зумом, вспышками на переходах и водяным знаком канала;
- файл `upload.txt` с названием, описанием, источниками, авторами фото и тегами.

Монтировать вручную ничего не нужно.

## Установка на Mac (один раз, ~10 минут)

Откройте **Терминал** (Cmd+Пробел → «Терминал») и вставляйте команды по одной.

1. Установите Homebrew (менеджер программ), если его ещё нет:
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
2. Установите ffmpeg (монтаж) и Python:
   ```bash
   brew install ffmpeg python
   ```
3. Скачайте проект и установите зависимости:
   ```bash
   git clone -b claude/youtube-german-video-content-7vk4lj https://github.com/varum12/varum12.github.io.git
   cd varum12.github.io/yt-factory
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. **Очень рекомендуется:** получите бесплатный ключ Pexels, тогда картинки станут видео и гораздо точнее подойдут по теме.
   - Зарегистрируйтесь на https://www.pexels.com/api/ и получите ключ.
   - Сохраните ключ, заменив `ВАШ_КЛЮЧ` на свой:
     ```bash
     echo 'export PEXELS_API_KEY="ВАШ_КЛЮЧ"' >> ~/.zshrc && source ~/.zshrc
     ```

   Без ключа конвейер берёт бесплатные фото из Openverse (Flickr, Wikimedia). Они подходят по теме хуже, и их авторов нужно указывать в описании. Конвейер делает это сам.

## Как сделать видео

```bash
cd varum12.github.io/yt-factory
source .venv/bin/activate
python3 factory.py scripts/de/001-gehirn-absturz.yaml
```

Готовое видео и `upload.txt` появятся в папке `output/`. Несколько видео подряд можно сделать одной командой:

```bash
python3 factory.py scripts/de/*.yaml
```

Длинную версию 16:9 из того же сценария делает флаг `--format long`.

## Сценарий

Сценарий — это файл `.yaml` в папке `scripts/<язык>/`. Пример: `scripts/de/001-gehirn-absturz.yaml`.

- `segments` — фразы. Каждая фраза озвучивается и показывается со своими картинками.
- `visuals` — что показать. Это либо поиск на английском (`"octopus underwater"`), либо имя файла или папки из `assets/media/`, если у вас есть свои картинки и видео.
- `highlight` — слова, которые выделяются жёлтым. Числа выделяются автоматически.
- `sources` — источники фактов. Обязательно для доверия зрителей и для монетизации.

## Перевод на другие языки

1. Попросите Claude перевести сценарий, например: «переведи scripts/de/001… на английский».
2. Сохраните перевод в `scripts/en/` с `lang: en`.
3. Запустите конвейер. Картинки берутся те же, голос и субтитры меняются сами.

Голоса для каждого языка настраиваются в `config.yaml`.

## Настройки (`config.yaml`)

- `channel_name` — водяной знак.
- `cut_seconds` — темп монтажа.
- `font_size`, `caption_y` — размер и высота субтитров.
- Голос и скорость речи для каждого языка.

## Музыка и звуки

- Положите `.mp3` в `assets/music/`. Конвейер выберет случайный трек и сделает его тихим фоном. Бесплатная музыка: YouTube Studio → Фонотека.
- Положите звук «вжух» в `assets/sfx/`. Он будет звучать на каждой смене фразы.
