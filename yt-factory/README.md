# YT Factory: конвейер для Shorts и длинных видео

Вы пишете сценарий (или просите Claude его написать), запускаете одну команду и получаете готовый ролик в мемной подаче. Монтировать руками ничего не нужно.

**Что делает конвейер:**
- **Озвучка** AI-голосом.
- **Субтитры:** в Shorts по одному слову, в длинных видео по три. Числа и ключевые слова выделяются жёлтым.
- **Быстрые склейки** с «ударом» зумом и медленным дрейфом.
- **Мемные приправы:** анимированные эмодзи, стикеры-надписи («WAS?!»), тряска, глитч и вспышка на смене фразы, мемные реакции из стоков.
- **Звуки** (вжух, поп, бум, дзынь, скрэтч) создаются сами, ничего скачивать не нужно.
- **Фоновая музыка** автоматически становится тише, пока говорит голос.
- **Громкость** выставляется по стандарту YouTube (−14 LUFS).
- **Для длинного видео:** обложка 1280×720, главы с таймкодами в описании и автоматическая нарезка Shorts.
- **Файл `upload.txt`:** название, описание, источники, авторы картинок и теги.

## Установка на Mac (один раз, ~10 минут)

Откройте **Терминал** (Cmd+Пробел → «Терминал») и вставьте:

```bash
git clone -b claude/youtube-german-video-content-7vk4lj https://github.com/varum12/varum12.github.io.git ~/yt
cd ~/yt/yt-factory
bash setup_mac.sh
```

Скрипт сам поставит Homebrew, ffmpeg, Python и всё нужное. По ходу он может попросить пароль от Mac.

**Очень рекомендуется: бесплатный ключ Pexels.** С ним вместо случайных фото будут подходящие по теме вертикальные видео и мемные реакции.
1. Зарегистрируйтесь на https://www.pexels.com/api/ и нажмите «Your API Key».
2. В Терминале замените `ВАШ_КЛЮЧ` на свой ключ и выполните:
   ```bash
   echo 'export PEXELS_API_KEY="ВАШ_КЛЮЧ"' >> ~/.zshrc && source ~/.zshrc
   ```

## Ежедневная работа

```bash
cd ~/yt/yt-factory
./video scripts/de/002-bueroklammer-haus.yaml        # один Short
./video scripts/de/*.yaml                            # все сценарии подряд
./video scripts/de/100-18-fakten-gehirn.yaml         # длинное видео + 5 Shorts из него
```

Результат появляется в папке `output/`. Открыть её можно командой `open output`. В каждой папке лежат видео `.mp4`, `upload.txt` и, для длинного видео, `thumbnail.jpg`.

**Неделя контента (14 Shorts + 3 длинных):**
1. Попросите Claude: «Напиши 3 длинных сценария по 15–18 фактов, у каждого 5 shorts, и 4 сценария-истории».
2. Положите файлы в `scripts/de/`.
3. Запустите `./video scripts/de/*.yaml` и оставьте работать.
4. Загрузите ролики через YouTube Studio и включите отложенную публикацию: по 2 Shorts в день, длинные видео во вторник, четверг и субботу.

## Как устроен сценарий

```yaml
title: "Название на YouTube #shorts"
lang: de
format: short                 # short = 9:16, long = 16:9
segments:
  - text: "Что говорит голос."
    visuals: ["octopus", "@shocked"]    # поиск на английском, @реакция или файл из assets/media
    emoji: "🤯"                          # анимированный эмодзи
    pop: "WAS?!"                         # стикер-надпись
    shake: true                          # тряска камеры
    sfx: boom                            # boom | ding | scratch | pop | whoosh | none
    chapter: "Название главы"            # только длинные видео: глава + граница для Shorts
highlight: [слова, которые, выделить]
shorts:                                  # только длинные видео
  - chapter: "Название главы"
    title: "Название Short #shorts"
```

Полные примеры лежат в `scripts/de/`.

**Реакции:** `@shocked`, `@laugh`, `@facepalm`, `@angry`, `@thinking`, `@wow`, `@sad`, `@money`, `@clap`, `@nope`, `@cool`, `@scared`. Список можно расширить в `config.yaml`. Реакции берутся из стоков, поэтому их можно использовать легально, в отличие от кадров из фильмов.

**Свои картинки и видео:** положите файл в `assets/media/` и укажите его имя в `visuals`.

## Голос

- Послушать все голоса: `./video --voice-samples de`. Образцы появятся в `output/voice-samples/de`.
- Выбранный голос и скорость речи впишите в `config.yaml` → `voices`.
- Когда появится доход, стоит перейти на ElevenLabs с коммерческой лицензией (план Starter, около $5 в месяц): там голоса живее. В `config.yaml` укажите `de: { engine: elevenlabs, voice: "<voice_id>" }` и выполните `export ELEVENLABS_API_KEY=...`.

## Перевод на другие языки

1. Попросите Claude: «переведи scripts/de/002… на английский».
2. Сохраните перевод в `scripts/en/` с `lang: en`.
3. Запустите конвейер.

Картинки, эффекты и тайминги перестроятся автоматически. Голоса для EN, RU и ES уже настроены в `config.yaml`. Для каждого языка заводится отдельный канал.

## Музыка

Положите 3–5 треков `.mp3` в `assets/music/`, и конвейер будет брать случайный. Бесплатная музыка для монетизированных видео: YouTube Studio → «Фонотека», треки с пометкой «указание автора не требуется».

Свои звуковые эффекты кладите в `assets/sfx/` с именами `whoosh.mp3`, `boom.mp3` и т. д. Они заменят встроенные.

## Важно для монетизации

- **Факты.** Перед публикацией проверьте каждый факт по ссылкам из `sources`. Одна ошибка в комментариях бьёт по доверию сильнее, чем десять удачных видео.
- **Только легальный контент:** стоки Pexels и Openverse и свои материалы. Никаких кадров из фильмов и чужих роликов, иначе YouTube не даст монетизацию.
- **Авторство.** Если в `upload.txt` есть блок «Bildnachweise», оставьте его в описании. Это требование лицензий CC BY.
- **Пометка об AI.** При загрузке в YouTube Studio отметьте «Изменённый или синтетический контент», если в ролике реалистичные AI-сцены. Для AI-голоса над стоковыми кадрами пометка обычно не нужна.
